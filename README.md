# 厝內 Tshù-lāi

> 一個開源的「數位家人」框架。給家人的聲音、照片和故事，它會成為一個住在家裡、
> 懂情境、會主動開口、說台語的陪伴者。

厝內（台語，「家裡」）從一個很個人的動機開始：作者的阿嬤確診癌症第三期。
模型每半年都在進步，但她的聲音、她講阿公時的語氣，只有現在能錄。
所以這個專案的第一個工具不是 AI，是一份訪談題庫和一支錄音 app。

## 它會做什麼

- **回到阿嬤家**，手機偵測到位置，她會說「轉來矣？食飽未？」
- **坐下來**，她會聊阿公、親戚、厝邊發生的事，記得你上次說過什麼
- **看電視**，她會問劇情、罵壞人
- **滑手機卡住**，她會問你「這个貼圖按怎傳？」
- **拍照時**，她可以坐中間或站邊邊，跟你合照
- **平時**，像 LINE 一樣傳台語語音訊息給你，早上傳早安圖
- **支援台語**，聽、想、說三段分開處理
- **plugin**，用 MCP 協定接新的話題來源、情境觸發、語音與影像引擎

## 架構

```
Client (Flutter)  ──WebSocket──▶  Persona Engine (Python, 家用主機)  ──▶  Memory Store (SQLite)
 定位 / 相機 / 麥克風                Scene 狀態機 / 對話腦 / 生活模擬器        人物關係圖 / 故事庫
 avatar 呈現 / 離線快取              台語 STT→LLM→TTS / 影像合成 / Plugin Host   對話日誌 / 人格卡
```

資料留在家裡。手機透過 Tailscale 私網連回家用主機，沒有雲端帳號、沒有上傳。
詳見 [docs/architecture.md](docs/architecture.md)。

## 專案狀態

| 階段 | 內容 | 狀態 |
| --- | --- | --- |
| 0 | 採集工具：訪談題庫、錄音整理、轉寫、人物標籤 | 進行中 |
| 1 | 聲音複製、人格卡、記憶、閒聊通道、桌面版文字對話 | 規劃 |
| 2 | 影像：待機影片、即時嘴型、合照 | 規劃 |
| 3 | 手機 app、geofence、scene 狀態機 | 規劃 |
| 4 | Plugin SDK、文件、社群 | 規劃 |

## 現在就能做的事

讀 [docs/data-collection.md](docs/data-collection.md)，拿起手機，去找你的家人。
那份文件列出要錄什麼、怎麼錄、怎麼整理，不需要任何技術。

```
app/         Flutter client
```

## 使用規範

程式碼採 MIT 授權。但這個專案處理的是真人的聲音和臉，請讀 [USE_POLICY.md](USE_POLICY.md)。
一句話版本：只做你自己家人的、經過同意的分身；不要拿去冒充任何人。
